# Installed skills

Vendored from https://github.com/Leonxlnx/taste-skill (MIT), at upstream
commit `ccbc156`. Only the `skills/` directory is copied — the upstream
repo's assets, research and examples are not needed at runtime and are large.

Each skill is self-contained: `name` and `description` frontmatter only, no
`allowed-tools`, and no references to files outside its own folder.

To update: re-clone upstream and copy `skills/*/` over this directory.
